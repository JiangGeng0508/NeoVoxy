# 后台生成停机与区块卸载让出

本阶段处理 roadmap 中“后台生成开启时退出卡住”的遗留项。后台生成仍默认开启，LIGHT 目标、生成并发、MSPT 阈值、画质及存储格式不变。

## 卸载忙循环

Minecraft 1.21.1 的 `ChunkMap.scheduleUnload` 等待 `ChunkHolder.getSaveSyncFuture()` 后执行回调。回调发现区块仍有生成引用，或新的保存依赖尚未完成时，会再次调用 `scheduleUnload`。保存 future 已完成而生成引用仍存在时，新回调立即进入同一个 `unloadQueue`。

正常 tick 受可用时间限制；停机时 `MinecraftServer.stopServer` 使用恒为 true 的时间供应器。`processUnloads` 因而可以持续消费自己刚入队的重试，无法返回区块调度循环，让需要主线程继续处理的生成任务释放引用。前一阶段两次 Iris 卡住的栈均停在 `CompletableFuture.postComplete`／`ChunkMap.processUnloads`。

新增通用 `MixinChunkMap` 在第一次取回调时记录队列长度，每次 `processUnloads` 最多取出这批数量。运行中产生的新回调留在原队列，下一次调用再处理；原版的时间条件仍能提前结束本轮。没有取消 future、伪造完成、丢弃区块或跳过保存。`ConcurrentLinkedQueue.size()` 每轮只额外读取一次，避免每次回调都遍历队列。

此限制覆盖客户端集成服及专用服，避免同样的队列重试饿死后续任务。它是回调数量边界，不是单次保存或 tick 的硬时间上限。若外部生成任务本身永远不释放引用，停机仍会等待它；本修复不会强制丢弃该任务。

## 生成票据释放

原 `DistantWorldGenerator.shutdown()` 先调用 fastutil 迭代器的 `remove()`，再读取刚才的 entry 坐标。fast entry 引用哈希表槽，删除时的移位可能让它指向另一个坐标，造成票据漏释放或重复释放。

现在先保存坐标并释放对应票据，成功后才删除任务。重复关闭不重复释放；释放抛出异常时，该任务仍保留供后续重试。生成 future 的完成与取消仍由原版区块系统管理。关闭、配置停用、SeedGen 交接和重置沿用同一释放路径。

## 验证方法

11 项定向回归涵盖哈希冲突与零坐标、重复关闭、释放失败保留、原版 future 所有权、保存已完成但生成引用仍在的重试、FIFO、异步完成、空队列，以及每轮只读取一次队列长度；并复跑现有生成背压测试。修复前两项票据回归失败，修复后全部通过。

新的 [独立游戏夹具](../scripts/distant-gen-smoke/README.md) 始终开启后台生成，使用源存档的独立副本。普通场景分别覆盖首次观察到生成中任务和摄取至少 128 个区块后退出，并支持直接关闭游戏及先返回标题界面。

确定性故障注入使用真实 `ChunkMap` 卸载入口、一个保存 future 已完成但仍持有生成引用的测试 holder，及停机使用的无限时间条件。修复前进入与历史记录相同的忙循环，超时后保留线程栈并终止测试进程。修复后要求先让出并保留待卸载 holder，释放测试引用后再次处理并移除它。测试 holder 没有区块载荷，不写入地形。

游戏验收要求生成任务确实出现、停机钩子清空生成器及专用票据、服务端保存完成、渲染器和 Voxy 实例关闭，以及进程正常退出；超时或强制终止不能计为通过。普通退出曾有一次成功，表明历史问题并非每次出现；确定性注入用于隔离并验证忙循环机制，不把它当作自然重现频率或性能收益。

两次直接调用 `Minecraft.stop()` 的 Sodium／Iris 运行均完成保存、票据清零、渲染器及实例关闭，并以退出码 0 结束，但关闭本地连接时记录 `ClosedChannelException`。Iris 的静音“返回标题界面”复跑也出现该错误。严格日志检查仍将这些运行记为失败，不过滤该错误；后续连接对照见下文，不将“退出未卡住”描述为整个退出场景的全部检查通过。

Sodium 的确定性重试加返回标题界面场景完整通过（`run-20261107-163151-sodium-cold`，87.54 秒含启动退出）。Iris 的最后一轮静音返回标题界面运行（`run-20261107-165225-iris-warm`，90.80 秒）通过全部收尾检查，因上述连接错误整体仍为失败。此前还有一轮未静音退出的 OpenAL 错误，以及返回菜单后人工进入另一世界、导致夹具超时的记录；这些记录均保留，未计作通过，也没有修改生产音频行为。

## 本地连接关闭对照

重新接入 RTX 4060 后，Iris 直接退出运行 `run-20261107-172401-iris-warm`（123.48 秒）再次完成全部收尾检查并以退出码 0 结束，严格日志检查因两个连接 ERROR 失败。夹具记录的首批失败包为原版 `ClientboundBlockUpdatePacket` 和 `PosRot`，分别在请求关闭后约 445／473 ms 失败；后续排队包中也有 `voxy:far_entities`，不能据此宣称 Voxy 没有在关闭过程中发包。

NeoForge 21.1.244 的 `Connection.doSendPacket` 为发送 future 登记失败传播；对端 LocalChannel 已关闭、本端尚未处理关闭时，排队写入可在 `LocalChannel.doWrite` 抛出 `ClosedChannelException`，随后 `Connection.exceptionCaught` 记录 ERROR。独立 `disconnect_control` 模组从启动 classpath 和模组目录排除 Voxy 输出，并检查已加载模组列表中没有 Voxy，使用同一源存档的新副本进行对照：

| 运行 | 条件 | 结果 |
| --- | --- | --- |
| `run-20261107-171913-iris-warm-control` | 不加载 Voxy，运行 180 个客户端世界 tick 后直接退出 | 121.53 秒，保存完成、退出码 0，无 ERROR，通过 |
| `run-20261107-172848-iris-warm-control` | 不加载 Voxy，使用有超时的事件循环门控，在对端关闭前排队原版时间包、关闭后再写入 | 96.15 秒，`ClientboundSetTimePacket` 抛出同类异常并产生一个连接 ERROR；保存完成、退出码 0，严格验收失败 |

受控复现未修改 `Connection`、关闭协议或错误日志处理，说明这个竞态机制不要求加载 Voxy。一次普通对照没有自然复现，不能证明其自然发生频率，也不能排除 Voxy 工作负载对时序的影响。诊断结果不把任何失败运行改为通过，不构成完整干净退出修复；卸载忙循环和票据释放的修复结论与此分开记录。

## 构建与回归归档

标准 build：341 项中 305 项通过、36 项 GPU 默认跳过，失败为零；Mixin 的 94 个注册、104 个目标及 282 个成员检查通过，10 个缺失可选目标跳过；中英各 232 个语言键及 137 个静态引用通过。首次验证后段仅检测到 Intel UHD Graphics，当时因缺少 `GL_ARB_gpu_shader_int64` 未执行完整 GPU 专项，该环境记录保留。

2026-11-07 重新接入显卡后执行 `build -PverifyGpu=true`：341 项全部通过，零失败、零跳过。36 项 GPU 测试均实际使用 RTX 4060 Laptop、OpenGL 4.6、NVIDIA 591.74，报告确认 64 位 shader 扩展可用。日志、JUnit XML、运行标记和硬件摘要分别归档为 `build-gpu.log`、`gpu-xml/`、`gpu-run.json`、`gpu-summary.json`；这补齐了本阶段 GPU 自动回归，不替代完整游戏或历史性能验收。

V1／V2 双客户端压力运行 `run-20261107-165531` 通过，含启动退出共 266.05 秒。两端各收到全部 2304 个最终金块区段和 600 个唯一缺失结果，本地存储复查通过；补发队列及修复标记归零，三进程正常退出。Slow 的 69 次容量拒绝后恢复，两端处理失败为零；服务端快照预算峰值 33,554,311 字节，未超过 32 MiB。该测试验证通用卸载 Mixin 接入专用服后的网络和停机回归，不代表性能对照。

原始证据位于 `build/reports/distant-gen-shutdown/`，包括首次启动超时、修复前票据测试失败及卸载忙循环线程栈。完整季节／Vista／SeedGen 联动、长期后台生成及历史版本同场景性能对照仍不由本阶段推断。

正式分发 JAR 已确认包含新卸载 Mixin，且不含游戏、连接对照、模型或网络测试探针。`build/reports/distant-gen-shutdown/verification.json` 保存源码及产物 SHA-256，并核对正式包内三个改动类与游戏实际加载的字节一致；状态为 `partial_game_acceptance`，明确保留通过的构建／网络回归和未通过的游戏日志检查。独立连接对照单列，记录其自身类哈希，不作为加载 Voxy 的验证。最终标准 build 移除可选探针，305 项 CPU 测试通过、36 项 GPU 默认跳过；显卡验收采用前述已归档的显式 GPU 运行。
