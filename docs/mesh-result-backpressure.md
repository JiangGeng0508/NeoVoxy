# 几何结果字节预算与背压

本阶段完成 roadmap 第三批的异步建面结果预算。摄取来源、节点请求／子区段更新队列仍需后续处理；第四批的上传容量探测与严格每帧 2 MiB 上传尚未实现。

## 预算和恢复

每个 `RenderGenerationService`／渲染器持有一个 `MeshResultBudget`。开始建面前，以非阻塞方式取得预留；预算不足时保留原任务 key，让调度器执行其他服务，不读取区段、不创建结果，也不丢弃更新。多个工作线程竞争同一预算，在调度检查后失去容量的线程归还服务执行票据，原任务仍留在队列。

| 计账范围 | 上限／预留 |
|---|---|
| 建面结果原生缓冲及运行中预留 | 合计 64 MiB |
| 结果 offsets 堆数组及运行中预留 | 合计 32 KiB |
| 运行中与已发布结果 | 合计 1024 项，空结果也占一项 |
| 单个运行中任务 | 原生 4,198,408 字节，堆数组 32 字节 |

单任务原生预留来自现有八个有界四边形桶的 4 MiB 最大结果，加最大 4104 字节 occupancy。完成后缩减为实际 `geometryBuffer.size + occupancy.size` 和 offsets 长度；未用空间立即返还。容量恢复后按原优先级运行，重新取得当前区段。缺模型、建面异常、关闭前尚未取得任务的路径均释放预留。

这意味着接近容量时会提前暂停：必须再容纳一个完整建面预留才允许开始，不能将可用的小块空间误认为能安全接受未知大小的结果。每次运行仍保持原有权重 4。

## 所有权

`BuiltSection` 持有预留直到其数据释放。所有权依次经过建面工作线程、`AsyncNodeManager` 输入队列、`BasicAsyncGeometryManager` 待复制集合。节点接收结果不提前归还预算；复制到同步暂存区后才释放完整结果，包含原先待上传路径遗漏的 occupancy。未复制结果被替换、节点移除、不再监听的结果丢弃和关闭排空，也通过同一释放入口归还一次。空结果更新现有节点同样归还条目。

关闭与结果入队串行化，关闭后到达的结果立即释放，避免在 drain 结束后遗留原生缓冲。建面服务关闭会等待正在运行的工作单元结束；已经交付消费者的结果仍由消费者负责释放，不因生产者关闭而提前失效。关闭节点管理器另清理其待复制集合。

SeedGen 使用的实际 `BuildTask`、`updatePriority()` 中的 `Math.min`、`processJob(RenderDataFactory, IntOpenHashSet)` 的队列 poll 和两处 `Consumer.accept` 均保留。本地 SeedGen 0.3.0 的新鲜度包装器在丢弃旧结果时调用 `BuiltSection.free()`，会同时返还预留；字节码检查不能代替完整 SeedGen 游戏验收。

## 统计范围

F3 分别报告建面结果原生实际占用／含运行中预留的总占用／上限，结果堆数组实际占用／总预留／上限，以及结果数和运行中数量。后台生成增加该预算的压力比，沿用超过 75% 暂停、所有下游低于 50% 恢复的滞回；即使可运行建面 key 为零，保留的大量结果也能暂停新生成。旧实例隔离规则继续适用。

节点的两个可复用同步暂存对象另显示 `Node sync native capacity KiB`，包含 geometry copy 数据、copy 头和 scatter 缓冲的已分配容量。它们在结果复制后独立拥有数据，不属于 64 MiB 建面结果预算。GPU 几何使用量／容量也单列。

以上不等同进程内存硬上限：工作线程的区段快照、固定四边形工作区、临时数组、对象头、任务 key／模型依赖集合、已接收的持久几何元数据 offsets、外部调用者创建的 clone、同步暂存及 GPU／上传流不在建面结果预算内。同步暂存数值是已保留容量，不包括扩容复制瞬间的两份分配。摄取及其他未完成队列仍可能持有来源对象；这些限制在 roadmap 中继续保持未完成。

## 验证

定向回归覆盖三类容量独立限制、预留缩减、空结果条目、失败转移、多线程竞争、保留结果阻止后续建面时其他服务仍可执行、恢复读取最新体素、缺模型与异常释放、运行中关闭、消费者所有权、节点空更新／丢弃，以及待复制结果替换／移除／关闭释放。原生分配计数用于检查 geometry 与 occupancy 一并释放。

Sodium／Iris 模型夹具增加每 tick 的建面结果预算断言和采样峰值，要求实际观察到结果活动。该峰值仅来自 tick 采样，不能当作分配瞬间的真实峰值。它与已有五类区段几何等价检查、Create 异步准备及 960 帧模型基准共同验证运行兼容性，不能据此推导历史版本性能收益。
