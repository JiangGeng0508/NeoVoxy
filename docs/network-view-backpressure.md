# V2 视距与生成背压

roadmap 第二批剩余实现增加了可选视距协商，以及后台生成的下游压力滞回。七个 V1 通道的注册版本、映射与区段数据编码、默认视距和存储格式保持兼容。

## 协商与过滤

新增三个可选通道：`hello_v2_c2s` 携带版本 2、维度和方块半径；`hello_v2_s2c` 确认版本 2；`view_distance` 更新维度和半径。只有基础同步通道及三个扩展通道均可用时，客户端才发送 V2 hello。旧端缺少扩展时使用原来的 V1 hello 和最大支持半径。没有 Voxy 的端仍可连接。

半径取现有 `sectionRenderDistance × 512`，限制为现有设置范围 320–32768 方块。客户端 level 尚未建立时推迟 V2 hello，tick 自动重试；断线清除协商状态。服务端只接受当前玩家维度的握手和视距更新，视距消息不能代替握手。映射修复与服务端维度重同步保留协议和半径，旧维度更新不能覆盖当前维度。

握手附带当前视距；客户端换维度立即上报，普通配置变化合并到最近值、最多每秒一次。发送失败不推进已上报状态；半径变化无需重新同步整个映射表。新确认与旧确认一样经过连接身份检查。

服务端对拉取登记、待发送请求、实时广播和溢出补发使用相同过滤：同维度，区段完整水平包围盒与玩家位置为圆心的视距圆相交。相切保留，粗级区段和负坐标适用同一规则；不以区段中心替代边界。每个玩家独立保存半径，V1/V2 玩家可以共用准备缓存和既有总量／每玩家发送预算。

客户端按成功上报的 V2 视距暂缓范围外拉取。离开范围或切换维度的在途需求归还网络窗口，保留 key；移动回范围或扩大视距后继续发送，不依赖再次触发存储 miss。已收到载荷继续走原有有序消费和确认。视距更新不是历史数据全量重同步；过滤外未发送的历史更新不会因此自动扫描补发。

## 生成压力

`DistantGenerationManager` 仍只调度本模组的集成服后台生成，不接管 Groundwork 或 SeedGen。客户端 tick 在渲染器所属线程读取建面任务和网络预算，发布带实例身份的不可变计数快照；服务端不访问渲染器或 OpenGL。建面数量包括可运行、执行中及等待模型的任务，模型上传预算仍沿用第一批只查看可运行队列的规则。

| 下游 | 压力分母 | 暂停新生成 | 恢复条件 |
|---|---:|---:|---:|
| 摄取 | 2000 个任务 | >1500 | <1000 |
| 保存 | 1200 个任务 | >900 | <600 |
| 建面 | 2000 个任务 | >1500 | <1000 |
| 客户端网络 | 64 MiB 或 1024 项，取较高占比 | >75% | <50% |

摄取、保存和建面是内部软任务预算，不宣称这些队列已有字节硬上限；后者属于第三批。网络使用载荷、解码预留及映射的现有预算。当前服务端权威同步与集成服生成不同时启用，网络压力输入为已有客户端网络管线预留统一判断入口，不能据此推断专用服生成受控。

任一下游超过高水位即暂停，全部下游低于低水位才恢复。MSPT 保留配置上限，达到上限暂停，恢复还要求低于上限的 90%。每个维度先执行 `harvest()`，再检查最新摄取／保存积压决定是否 `topUp()`；已生成任务继续收获、摄取、保存和释放票据。压力暂停不调用 shutdown。实例切换和服务器停止清除旧门控状态，旧实例的客户端计数不影响新实例。

## 自动验证

新增回归覆盖 V1/V2 混合协商、没有 Voxy 的端、连接过期确认、三个新增 codec、发送字节计费、负坐标／相切／圆角排除、粗区段边界、半径夹取、动态缩小／扩大、维度切换、映射修复、配置更新节流、发送失败重试、范围外请求保留及全部下游滞回和 MSPT 恢复边界。

```powershell
.\gradlew.bat testJunit --offline --console=plain --tests '*LodViewDistanceTest' --tests '*LodClientViewTest' --tests '*GenerationBackpressureTest' --tests '*VoxyNetworkTest' --tests '*VoxyClientNetworkTest' --tests '*LodServerSchedulerTest' --tests '*LodSectionRequestsTest'
.\gradlew.bat writeNetworkStressLaunch -I scripts/network-stress.gradle -PstressPort=54187 --offline --console=plain
python scripts/network-stress/run.py --fixture build/reports/lod-requests/server/smoke-world --port 54187
.\gradlew.bat build --offline --console=plain
```

双客户端探针让 Slow 在注册阶段移除三个 V2 通道，实际协商 V1；Fast 从 320 方块 V2 半径开始。远端标记广播应只到 Slow，Fast 的范围外直接请求也不得收到数据；随后 Fast 将现有视距设置扩大到 32768 方块，两端继续原有 2304 个金块区段、600 个唯一缺失区段、慢连接、溢出恢复、最终本地存储和正常退出验证。探针源码只用于专用 init 构建，标准 build 移除它们。

本轮不更改 GPU 路径。生成压力阈值由 CPU 回归验证；后台生成、Iris／Vista／SeedGen 的完整游戏负载及同场景 0.2.19 性能对照仍需单独验收，不能从网络有限突发测试推断帧时间提升。
